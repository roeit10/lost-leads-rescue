# הצלת לידים אבודים — Claude Code Skill

בכל עסק יש אנשים ששאלו כמה זה עולה, ואף אחד לא חזר אליהם.
הם לא ב-CRM — הם אף פעם לא הפכו ללקוח. הם פשוט נפלו.

הסקיל הזה עובר על **המייל והוואטסאפ** שלך, מוצא אותם, מדרג לפי כמה כסף מונח שם,
ומכין לכל אחד תשובה מוכנה.

**הוא לא שולח כלום.** אתה קורא, מתקן משפט, ושולח בעצמך.

---

## מה מקבלים בסוף ריצה

- **לוח HTML** — כרטיס לכל ליד: מה הוא שאל (בלשונו), כמה זמן עבר, כמה כסף
  מוערך, והטיוטה בפנים עם כפתור העתקה. בראש המסך: **סך הכסף שמונח על הרצפה.**
- **טיוטות אמיתיות בתיבה** — בשרשור הנכון, לא כמייל חדש מנותק.
- **דירוג לפי ערך** — לא לפי תאריך. מתחילים מהליד ששווה הכי הרבה.
- **שורת כיסוי כנה** — מה נסרק, מאיזה תאריך, ומה לא. תמיד בראש.

## שלושה סוגי לידים אבודים

| | מה קרה |
|---|---|
| 🔴 **מעולם לא נענה** | פנה, ואין שום תשובה בשרשור. הכי כואב, הכי קל להציל |
| 🟠 **נעצר באמצע** | הייתה שיחה, אולי יצאה הצעה, ואז שקט |
| 🟡 **הבטחה שנשכחה** | "אחזור אליך", "אשלח לך" — ולא קרה |

לכל סוג ניסוח אחר. זה מה שגורם לטיוטה להישמע כמו בן אדם.

## מה צריך

1. **Claude Code** מותקן.
2. **מייל מחובר** — דרך Composio (החיבור מהשיעור על חיבורים).
3. **וואטסאפ — אופציונלי.** חשבון ב-`greenapi.com` (יש שכבה חינמית), או פשוט
   ייצוא צ'אט רגיל מהאפליקציה.

בלי וואטסאפ הסקיל עדיין עובד — על המייל בלבד, ויגיד לך את זה.

```
# פעם אחת — הקונטקסט העסקי והחיבורים
```

## ⚠️ לפני שמחברים וואטסאפ — דבר אחד שחייבים לדעת

Green API **לא רואה אוטומטית את ההיסטוריה שלך.** מופע חדש מקבל את רשימת הצ'אטים,
אבל את תוכן ההודעות רק **מרגע החיבור והלאה**.

כדי לקבל היסטוריה, צריך להדליק את שמירת ההיסטוריה **לפני סריקת ה-QR הראשונה**.
האשף בסקיל עושה את זה בשבילכם ובסדר הנכון.

כבר חיברתם מופע קודם? צריך לנתק ולסרוק QR מחדש — הסקיל ילווה אתכם, ויזהיר
אתכם קודם אם למופע מחוברת מערכת אחרת שעלולה להיות מוצפת.

**המסלול הפשוט, בלי חשבון ובלי סנכרון:** ייצוא צ'אט. ראו למטה.

## 📤 ייצוא צ'אט מוואטסאפ — המסלול שמגיע הכי עמוק אחורה

זה הפיצ'ר המובנה של וואטסאפ. הוא לא דורש Green API, לא דורש חשבון, לא עולה כלום,
**ומגיע אחורה עד תחילת השיחה** — רחוק יותר ממה ש-Green API יכול להביא.

### אנדרואיד
1. לפתוח את הצ'אט
2. ⋮ (שלוש נקודות מימין למעלה) → **עוד** → **ייצוא צ'אט**
3. לבחור **בלי מדיה** ← חשוב. עם מדיה זה קובץ ענק והסקיל לא צריך אותה
4. לשמור את הקובץ (Drive, מייל לעצמכם, כל דרך שנוחה)

### אייפון
1. לפתוח את הצ'אט
2. ללחוץ על **שם איש הקשר** בראש המסך
3. לגלול למטה → **ייצוא צ'אט**
4. לבחור **בלי מדיה**
5. לשמור את הקובץ

### ואז
ליצור בתיקיית העבודה תיקייה בשם `whatsapp-export/`, ולשים בה את קובצי ה-`.txt`.
אפשר כמה קבצים — הסקיל קורא את כולם.

```
התיקייה-שלכם/
  whatsapp-export/
    צ'אט WhatsApp עם דני כהן.txt
    צ'אט WhatsApp עם מיכל רוזנברג.txt
```

זהו. בריצה הבאה הסקיל יקרא אותם אוטומטית, יחד עם מה שהוא מושך מ-Green API,
ויגיד לכם בשורת הכיסוי מה הגיע מאיפה.

**לא צריך לייצא את כל הצ'אטים.** מספיק אלה שאתם חושבים שיש בהם פניות עסקיות.

> 💡 **אין לכם Green API בכלל?** זה בסדר. הסקיל יעבוד על המייל + קובצי הייצוא בלבד,
> ויגיד לכם בפירוש שהוואטסאפ החי לא חובר.

## מה הסקיל לא עושה

- **לא שולח.** אף פעם. גם לא אם תבקשו באמצע ריצה.
- **לא נוגע בתיבה ולא בוואטסאפ** — לא מוחק, לא מארכב, לא מסמן כנקרא.
  הכל נראה בסוף בדיוק כמו בהתחלה, חוץ מתיקיית הטיוטות.
- **לא ממציא סכומים.** שירות שלא מזוהה → "לא ידוע", והוא לא נספר בסך הכולל.
- **לא כותב טיוטה לקו אדום** — מו״מ על מחיר, לקוח כועס, כל דבר משפטי.
  אלה עולים בלוח עם הסיבה, ואתם מטפלים.
- **לא מדווח "הושלם" על ריצה חלקית.** ערוץ שלא נסרק נאמר בשורה הראשונה.
- **לא CRM.** הוא עונה על שאלה אחת: מי פנה ולא נסגרה לו הלולאה.
