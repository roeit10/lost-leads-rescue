# וואטסאפ — Green API

## ⚠️ הדבר הראשון שצריך להבין

Green API **לא רואה אוטומטית את ההיסטוריה שלך.** מופע טרי מחזיר:

- `getChats` → **כן**, רשימת כל הצ'אטים מהטלפון, עם שמות ומספרים.
- `getChatHistory` → **תוכן רק לצ'אטים שעברו דרך המופע מאז שחובר.** צ'אט מלפני
  חצי שנה יחזיר `[]`.

זה נמדד בפועל: במופע חי, 6 מתוך 8 צ'אטים אישיים החזירו אפס הודעות, והיחיד שהחזיר
היה זה שהיה פעיל אחרי החיבור.

**אל תדווח למשתמש "לא נמצאו לידים בוואטסאפ" לפני שבדקת מה טווח הכיסוי האמיתי.**
"לא נמצא" ו"לא נסרק" זה לא אותו דבר, והבלבול ביניהם הוא השקר הכי קל לספר כאן.

---

## איך כן מקבלים היסטוריה

וואטסאפ מסנכרן היסטוריה למכשיר מקושר **רק ברגע הקישור**. לכן:

### 1. להדליק את ההגדרות *לפני* הסנכרון

```bash
curl -X POST "$GREEN_API_URL/waInstance$ID/setSettings/$TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"incomingWebhook":"yes","outgoingMessageWebhook":"yes","enableMessagesHistory":"yes"}'
```

לוקח עד 5 דקות להיכנס לתוקף.

### 2. Logout ואז סריקת QR מחדש

זה מה שמכריח את וואטסאפ לשפוך את ההיסטוריה ליומן של Green API. בלי זה,
ההגדרות מהשלב הקודם חלות רק על מה שיגיע מכאן והלאה.

```bash
curl -X GET "$GREEN_API_URL/waInstance$ID/logout/$TOKEN"
# ואז: קונסולת greenapi.com → סריקת QR מהטלפון
```

### 🛑 לפני שעושים logout — לבדוק webhook

```bash
curl -s "$GREEN_API_URL/waInstance$ID/getSettings/$TOKEN"
```

יש `webhookUrl` מוגדר? **המופע הזה משרת משהו אחר בפרודקשן.** סנכרון היסטוריה
עם `enableMessagesHistory:yes` ישלח אלפי הודעות ישנות לכתובת הזאת ויציף אותה.

הסדר הבטוח:
1. לשמור את ה־`webhookUrl` הקיים בצד
2. לרוקן אותו (`"webhookUrl":""`)
3. logout → QR → להמתין לסנכרון
4. למשוך את מה שצריך
5. **להחזיר את ה־webhookUrl**

**לעולם לא לעשות את זה בלי לשאול את המשתמש קודם.** מופע וואטסאפ מחובר הוא
תשתית חיה, לא סביבת בדיקות.

### 3. מה עדיין יחסר

וואטסאפ נותן למכשיר מקושר רק את מה שהוא בוחר לתת — בדרך כלל חלון מוגבל,
לא הכל מההתחלה. הודעות שנמחקו לא יחזרו.

**לכן: אחרי משיכה, תמיד לחשב את התאריך הישן ביותר שהתקבל בפועל ולדווח אותו
כטווח הכיסוי.** לא להניח שהחלון שהמשתמש ביקש הוא החלון שהתקבל.

## המסלול החלופי — ייצוא צ'אט

עובד לכל אחד, בלי חשבון ובלי סנכרון, **ומגיע אחורה עד תחילת השיחה** — עמוק יותר
מכל מה ש-Green API יכול להביא.

**להסביר למשתמש בדיוק ככה:**

- **אנדרואיד:** פותחים את הצ'אט → ⋮ → **עוד** → **ייצוא צ'אט** → **בלי מדיה**
- **אייפון:** פותחים את הצ'אט → לוחצים על **שם איש הקשר** בראש → גוללים למטה →
  **ייצוא צ'אט** → **בלי מדיה**

"בלי מדיה" הוא לא ניואנס — עם מדיה מקבלים ארכיון ענק שאין בו שום ערך לסקיל.

שומרים את קובצי ה-`.txt` ב-`whatsapp-export/` בתיקיית העבודה. אפשר כמה.

### קריאת הקבצים

הסקיל קורא כל `.txt` בתיקייה. הפורמט:
```
[12.3.2026, 14:22] דני כהן: כמה עולה אצלך אבחון?
```

- **שם הצ'אט מגיע משם הקובץ** (`צ'אט WhatsApp עם דני כהן.txt`), לא מהתוכן.
- שורת "ההודעות והשיחות מוצפנות מקצה לקצה" — לדלג.
- הודעות מערכת (`הצטרף/ה באמצעות קישור ההזמנה`, `<המדיה לא נכללה>`) — לדלג.
- פורמט התאריך משתנה לפי הגדרות המכשיר (`12.3.2026` מול `3/12/26`). **לזהות לפי
  ההקשר ולא להניח** — טעות כאן הופכת ליד מלפני חודש לליד מלפני שנה.

### מתי להציע את זה

- אין למשתמש Green API → זה המסלול היחיד, ועובד מצוין.
- Green API מחובר אבל הכיסוי קצר → **להציע את זה אקטיבית.** משתמש שרואה
  "נסרק מ-26.8 בלבד" צריך לשמוע שיש דרך להגיע רחוק יותר.
- המשתמש לא רוצה לגעת במופע חי → זה הפתרון.

## הקריאות עצמן

בסיס: `$GREEN_API_URL/waInstance$ID/<method>/$TOKEN`

⚠️ ה־`apiUrl` הוא **של המופע** (`https://XXXX.api.greenapi.com`), לא
`api.green-api.com` הכללי. שימוש בכתובת הכללית מחזיר `401` בלי הסבר —
וזו טעות שקל מאוד לבזבז עליה חצי שעה.

| שיטה | מה | הערות |
|---|---|---|
| `getStateInstance` | GET | חייב להחזיר `authorized` לפני הכל |
| `getSettings` | GET | לבדוק `webhookUrl` ו־`enableMessagesHistory` |
| `getChats` | GET | רשימת הצ'אטים. עובד תמיד, גם בלי היסטוריה |
| `getChatHistory` | POST `{chatId,count}` | התוכן. `count` מקסימלי 100 |

**קצב:** להשהות ~1.5 שניות בין קריאות. סריקה של 1,000 צ'אטים ברצף תיחסם.
בפועל אין צורך — לסנן קודם לפי `getChats` למי שאינו קבוצה, ולמשוך רק אותם.

**קבוצות** (`@g.us`) — לדלג כברירת מחדל. הן רועשות ולידים כמעט לא מגיעים משם.
המשתמש יכול לבקש לכלול.

## שליחה

**אין.** הסקיל לא קורא ל־`sendMessage`, בשום מצב. הטיוטות לוואטסאפ הן טקסט
בלוח, להעתקה ידנית.
