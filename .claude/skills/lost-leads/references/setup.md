רץ פעם אחת. **קודם שואב, אחר כך שואל.** אף אחד לא עונה על שאלה שכבר ענה עליה
במדריך קודם.

## שלב 1 — לחפש לפני שמדברים

חפש בתיקייה ובתיקיות שמעליה:

| מקור | מה לוקחים |
|---|---|
| `business-context.md` | הכל. זה הקובץ המשותף לכל הכלים בסדרה |
| **`context/business-context.md`** | אותו קובץ, במבנה "המשרד הדיגיטלי". **לבדוק גם כאן** |
| `context/business.md` | פרטי העסק ממיפוי העסק |
| `pricing.md` / `context/pricing.md` | מחירים ממחשבון התמחור |
| `../business-context.md` | תיקיית אב — מדריך קודם בסדרה |

חיפוש בפועל:
```bash
ls business-context.md context/business-context.md ../business-context.md 2>/dev/null
```

מצאת `business-context.md`? **הצג סיכום של 4-5 שורות ובקש אישור.** אל תבקש
מהמשתמש למלא מחדש מה שכבר קיים.

חסר רק חלק? שאל **רק על החסר**.

### וואטסאפ — Green API

🔑 **הסדר כאן קריטי. אל תשנה אותו.**

וואטסאפ מסנכרן היסטוריה למכשיר מקושר **רק ברגע הקישור**. לכן מדליקים את שמירת
ההיסטוריה **לפני** שהמשתמש סורק את ה-QR בפעם הראשונה. עשית את זה בסדר הנכון —
הסריקה שהוא עושה ממילא מביאה גם את ההיסטוריה, בלי שום צעד נוסף מבחינתו.

עשית את זה בסדר הפוך → הוא יצטרך לנתק ולסרוק שוב. חיכוך מיותר שקל למנוע.

**1.** המשתמש פותח חשבון ב-`greenapi.com` ויוצר מופע — **ועוצר. בלי לסרוק QR.**

**2.** יוצרים `.env` עם placeholder ופותחים לו אותו בעורך:
```bash
open .env
```
```
GREEN_API_URL=https://XXXX.api.greenapi.com
GREEN_API_ID_INSTANCE=
GREEN_API_TOKEN=
```
הוא מעתיק מהקונסולה את `apiUrl`, `idInstance` ו-`apiTokenInstance`, מדביק, ושומר.

⚠️ ה-URL הוא **של המופע** (מתחיל בארבע ספרות), לא `api.green-api.com` הכללי.
שימוש בכללי מחזיר `401` בלי הסבר.
**לעולם לא לבקש להדביק את הטוקן בצ'אט.**

**3.** מדליקים היסטוריה — **עכשיו, כשיש טוקן, ולפני הסריקה:**
```bash
curl -X POST "$GREEN_API_URL/waInstance$ID/setSettings/$TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"enableMessagesHistory":"yes","incomingWebhook":"yes","outgoingMessageWebhook":"yes"}'
```
להמתין דקה.

**4.** **עכשיו** שולחים אותו לסרוק QR מהטלפון. להמתין 5-10 דקות לסנכרון.

**5.** לאמת: `getStateInstance` צריך להחזיר `authorized`.

**6.** מופע שכבר היה מחובר מקודם? ראה `whatsapp.md` — צריך logout וסריקה מחדש,
**ולבדוק webhook קיים לפני כן.**

**7.** **להסביר את מגבלת ההיסטוריה** — ראה `whatsapp.md`. אל תשאיר את המשתמש
לגלות לבד שהסריקה ריקה.
