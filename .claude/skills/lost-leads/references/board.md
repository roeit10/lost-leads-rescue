# הלוח — `outputs/lost-leads.html`

קובץ אחד עצמאי. **בלי CDN, בלי אינטרנט, בלי פונטים חיצוניים.** נפתח בדפדפן,
עובד בטלפון, ונשלח כקובץ למי שצריך.

## הדאטה

בראש ה-`<script>`, אובייקט `DATA` יחיד עם כל הלידים. **מקור האמת הוא הדוח —
בנייה מחדש דורסת את הקובץ.** ערוך ידנית רק כשיודעים שזה זמני.

```js
const DATA = {
  coverage: { email:{from:"2025-09-01", count:842}, whatsapp:{from:"2026-08-26", count:50, partial:true} },
  leads: [{
    name:"דני כהן", channel:"email", date:"2026-03-12", daysAgo:177,
    wound:"never-answered", service:"אבחון AI לעסק", value:3500,
    heat:3, score:825, quote:"כמה עולה אצלך אבחון?",
    draft:"...", threadId:"...", flag:null
  }]
};
```

## המסך

### 1. כותרת — הרגע שמוכר את הסרטון
המספר הגדול: **סך הכסף המשוער שמונח על הרצפה**, ומתחתיו כמה לידים ובאיזה טווח.

לידים עם `value:null` **לא נספרים בסכום** — ומופיע לידו "+N בלי סכום ידוע".
לעולם לא להשלים אותם בהערכה כדי שהמספר ייראה גדול יותר.

### 2. שורת כיסוי — קבועה, מתחת לכותרת
> נסרקו 842 מיילים מ-1.9.2025 · וואטסאפ: 50 הודעות מ-26.8.2026 בלבד ⚠️

`partial:true` → סימון ברור. **זו לא הערת שוליים.** משתמש שחושב שנסרקה שנה
ובפועל נסרק שבוע יקבל החלטות שגויות.

### 3. כרטיס לכל ליד
- שם + ערוץ (אייקון) + כמה זמן עבר
- תג הפצע בצבע: 🔴 לא נענה · 🟠 נעצר · 🟡 הבטחה
- הסכום המשוער, או `לא ידוע` באפור
- **הציטוט שלו** — מה הוא כתב בפועל
- הטיוטה בתיבה עם **כפתור העתקה**
- מייל → קישור לטיוטה ב-Gmail. וואטסאפ → העתקה בלבד
- `flag:"red-line"` → במקום טיוטה, פס ההסבר למה זה עובר לטיפול ידני

### 4. סינון
לפי ערוץ · לפי סוג פצע · לפי טווח זמן. ברירת מחדל: הכל, ממוין לפי ניקוד.

## מפרט קבוע (זהה לכל כלי HTML בסדרה)

- **עברית RTL**, גופן מערכת
- **טולטיפ ❔ ליד כל מדד** — CSS בלבד. ⚠️ להזריק רק לאלמנטים סטטיים,
  לא למה שנוצר ב-`innerHTML`
- **`localStorage`** — מה סומן כטופל, ומה נסגר. עטוף ב-`try/catch`:
  בחלון פרטי הגישה זורקת, והדף חייב להיטען נכון בלי ערך שמור
- **אדום שמור להתרעות בלבד** — לא לעיצוב
- **חסר מוצג "חסר", לא אפס**
- פאנל הגדרות מתקפל לברירות המחדל

## מה אין בלוח

אין שליחה. אין "שלח לכולם". אין תיבת סימון המונית שמובילה לפעולה.
**הלוח מציג ומעתיק. הפעולה נעשית על ידי המשתמש, במקום שבו הוא מדבר עם הלקוח.**
